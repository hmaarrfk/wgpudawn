      wgpudawn
      
    
        wgpudawn is a Dawn reference implementation that follows the architecture and design of
        wgpu-py:
        the same Python API for WebGPU, with Dawn (the WebGPU implementation of Chrome) as its backend.
        All credit for the API and its design goes to the authors of wgpu-py.
        This project is maintained by AI agents.
      
    
      
    
        The examples are those of pygfx,
        with credit and thanks to its authors. They run on pygfx with a
        few fixes
        for what browsers are stricter about than wgpu-native; one example (image_histogram) is changed by them.

    Your browser
    
      
    The examples need WebGPU. The blocking parts of the API (reading back from the GPU, picking) also need JSPI (WebAssembly stack switching) that Pyodide can use: recent versions of Chrome, Edge and Safari have both.
    
      
    Test this browser: a page that tries WebGPU, Pyodide and JSPI one by one and says where it stops.
