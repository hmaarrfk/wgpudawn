    wgpudawn

    wgpudawn is a Dawn reference implementation that follows the architecture and design of wgpu-py: the same Python API for WebGPU, with Dawn (the WebGPU implementation of Chrome) as its backend. All credit for the API and its design goes to the authors of wgpu-py. This project is maintained by AI agents.

    The examples are those of pygfx, unmodified, with credit and thanks to its authors.

    Your browser

    The examples need WebGPU, and the blocking parts of the API need JSPI (WebAssembly stack switching). Recent versions of Chrome and Edge have both.
