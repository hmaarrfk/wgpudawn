# wgpudawn examples

These are the wgpu-py examples that do not depend on wgpu-native specifics,
with `import wgpudawn as wgpu`.

The `gui_*` and `imgui_*` examples use [rendercanvas](https://github.com/pygfx/rendercanvas),
which imports `wgpu` by name; see the README on running libraries that import
`wgpu` on top of wgpudawn.
